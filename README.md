# Digital Sari-sari Store

A mobile-first online store for a neighborhood sari-sari shop. Customers browse
products, add them to a cart and place delivery orders; the store owner manages
products, orders and settings from an admin dashboard.

**Live:** https://digitalsaristore.vercel.app

## Features

- Product catalog with categories, search and popular items
- Cart and checkout with delivery ordering
- Customer accounts and order history
- Admin dashboard for products, orders and store settings
- Bottom navigation designed for phones

## Tech Stack

- React 19 + TypeScript
- Vite + Tailwind CSS
- Firebase Authentication and Cloud Firestore
- Supabase
- Express

## Getting Started

```bash
npm install
cp .env.example .env.local   # then fill in your Firebase and Supabase keys
npm run dev
```

## Build

```bash
npm run build
```
